# GitHub setup (optional; no Codex required)

**Use only the new repository. Do NOT modify `ferrysrt/slangfeed` (Godot).**

The GitHub connector available in this chat can inspect and update an existing repository, but did not expose the creation action. To make a new one:

1. Visit https://github.com/new while logged in to `ferrysrt`.
2. Repository name: **`Slangverse-Android`**. Select **Private**.
3. Prefer an empty repository (no autogenerated README/license), since this ZIP already includes a README and `.gitignore`.
4. Extract `Slangverse-Android-Direct.zip`. Open a terminal in the extracted `Slangverse-Android-Direct/` folder.
5. Use Git commands below, replacing the remote only if your owner differs:

```bash
git init
git branch -M main
git add .
git commit -m "Initialize Slangverse native Compose and backend V2.2"
git remote add origin https://github.com/ferrysrt/Slangverse-Android.git
git push -u origin main
```

After creating the repository and confirming its access in ChatGPT, updates can be coordinated directly here through the connected GitHub app, **without Codex Cloud**.

All `.env`, `local.properties`, keystores, caches, and build output must remain private and untracked. Build and test on Android Studio; do not put API credentials in Android source. The project may need an official Gradle wrapper generated locally (see README).
